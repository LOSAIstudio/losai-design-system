# Project instructions

## Never delete without asking

Ask Leo before deleting **anything** — files, folders, documents, assets, repo copies, or earlier versions of a deliverable. This includes files I judge to be superseded, stale, duplicated, or wrong. Superseded versions are history and are Leo's to discard, not mine.

If something looks redundant or conflicting, say so and recommend removing it, then wait for a yes.

(Context: I deleted `standards/LOSAI-Brand-Standards.html` — the v1 standards doc — on my own judgement because it held outdated values. It was unrecoverable, and the zip had already been rebuilt without it.)
